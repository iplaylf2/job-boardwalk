# Documentation

Start with the document for the work you need to do:

| Task                                              | Document                                                                 |
| ------------------------------------------------- | ------------------------------------------------------------------------ |
| Run the supported Compose deployment              | [Deployment](deployment.md)                                              |
| Use a portable desktop prerelease                 | [Desktop distribution](desktop-distribution.md#use-a-desktop-prerelease) |
| Build, check, or release the repository           | [Development](development.md)                                            |
| Understand product responsibilities and authority | [Product design](product-design.md)                                      |
| Use or maintain an application's interfaces       | [Application READMEs](../apps/README.md)                                 |

Cross-application behavior belongs in Product design; API, UI, and implementation details belong
with the application that owns them. Deployment and Desktop distribution define their respective
runtime layouts. The [packaged desktop readme](../internal/desktop-distribution/assets/readme.md)
is the user guide included in portable archives.
